    この管理画面について

    ● 保存先（簡易ファイルDB）：付属の Node サーバー起動中は、入力が server/data/chat-logs.ndjson（1行=1レコードのNDJSON）に保存され、全訪問者分が集約されます。この画面はそのファイルを読み出して表示します。
    ● 起動方法：html/server/ で npm start（または node server.js）→ ブラウザで http://localhost:3000/admin.html を開く。
    ● フォールバック：サーバー未起動／file:// で直接開いた場合は、そのブラウザの localStorage の記録を表示します（上部バナーに取得元を表示）。
    ● セキュリティ：このログイン枠は簡易的なものです。公開運用時はサーバー側の認証・アクセス制限へ置き換えてください。サーバーに ADMIN_TOKEN を設定した場合は、本ファイル冒頭の ADMIN_TOKEN に同じ値を設定してください。
    ● 個人情報：自由入力には個人情報が含まれる可能性があります。保管期間は社内ルールに従い、不要時は「ログ消去」を。
